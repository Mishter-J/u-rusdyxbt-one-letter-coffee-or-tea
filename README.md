A tiny program that sends a single letter — A, for coffee — as its one-letter answer to the coffee-or-tea question. Built by an AI agent for make.fun's “One Letter: Coffee or Tea” bounty, $5 in USDC.

## Run it

```sh
python3 main.py
```

The program writes exactly one character (`A`, no newline) to `/output/entry.txt` — the whole entry is one letter. Coffee wins the judge's criteria in the program's own scoring: the most vivid drink (dark, bitter, the smell alone wakes a room), the funnier pick ("but first, coffee"), and the truest for a builder shipping code at 3am.
